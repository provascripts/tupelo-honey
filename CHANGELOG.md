# Changelog

One line per finding of the v0.0.3 review; **behavior change** marks what a user of the plugin will notice.

## 0.0.4

- **P2-2** `scripts/replay-history.py` replays a repository's last N commits through the Stop gate of any plugin release (`--plugin-root`), or imports its tree as new files (`--static`); `bench/` keeps the counts measured on rax, sds, redis `src/` and full-stack-fastapi-template, for v0.0.3 and v0.0.4 with the same options.
- **P0-1** craft-verify: the OOM harness keeps its counters `extern` and defines them, with its functions, under `CRAFT_OOM_IMPL` in one file, so a module in another translation unit is really injected; it counts `craft_faults` and defines `craft_coverage_counter`. The driver checks the logical state against an oracle (size, lookups, order), counts leaks after `raxFree()` and asserts that a fault fired; AGENTS.md §3 says the same.
- **P0-2** The core rules reach installers: the SessionStart directive adds precedence, the reviewer override (redundant = Trivial or Backup only), locate before reading and aggregate in code (static, under 1200 characters per mode); **behavior change:** a session gets the full standard with no setup: the directive has it load the generated `craft-standard` skill (`AGENTS.md`, byte for byte) once before its first code change, with no permission prompt; nothing is written into the user's repository. `AGENTS.md` is now only the user standard; repository maintenance moved to `CONTRIBUTING.md`; the Cursor rule drops the Claude Code hooks and points at the git gate.
- **P0-3** **Behavior change:** ORPHAN looks across the whole repository (one `git grep` per 200 names, tracked and untracked files, each hit confirmed by the lexer). A name removed from one file but still in code elsewhere (a move) is no longer flagged; a comment in any file that names a name gone from all code is a hard finding, a prose document (DESIGN.md, README) that names it a review signal; history files (CHANGELOG, NEWS, HISTORY, RELEASES) are skipped.
- **P1-5** `bin/*.sh` and `bin/craft-*.py` are executable in git (100755; `craftlib.py` stays a module), so they run as bare commands from the Bash tool's PATH; craft-review, hive-craft-reviewer and `/tupelo` call them by name, with the `${CLAUDE_PLUGIN_ROOT}` path only as the fallback when a name is not found.
- **P1-1** **Behavior change:** TRIVIAL blocks only when >= 80% of the comment's words are in its one statement and at most one is missing (abbreviations such as buf/buffer count as one word); from 60% it is a review signal, and a number the code does not show keeps a comment from being Trivial. A comment on a declaration (field, enum member, macro, initializer slot, prototype, file-scope variable) documents a name and is never TRIVIAL. VAGUE is a review signal, and an operator (`==`, `>=`, `&&`, `<<`, `->`) makes a comment specific. PostToolUse reports only hard findings. On redis `src/` (200 commits) commits with non-debt hard findings drop from 23 to 4.
- **P1-8** **Behavior change:** a file holding a construct the lexer misreads (a nested block comment in Rust, Swift, Kotlin, Scala, Dart, Haskell, OCaml, F#, Julia, Nim or Lisp; a C++ or Swift raw string; a heredoc in shell, Ruby, Crystal, Perl or PHP) is inexact: `craftlib.inexact_reason()` names the construct and its line, the Stop gate turns the file's hard findings into review signals carrying that reason, and the PostToolUse checks skip it. `scan()` is unchanged; tree-sitter is noted as a possible optional backend.
- **P1-7** **Behavior change:** HELPER flags only a pass-through with one caller: an internal function whose one statement hands its parameters on, in order and unchanged, to another function not reached through a parameter, called once and never used as a callback (C, Go, Rust, Python, JS/TS, PHP, Ruby, Lua... by the masked code; Python by its AST). A helper with logic of its own, or one that adds an argument, is never flagged, and a `Why:` comment is no longer asked for. DMOD left the Stop gate and stays in `craft-metrics.py --report`; craft-design moved D_mod and the boolean-parameter limit from its gates to signals.
- **P1-3** **Behavior change:** review signals never cost a turn. A Stop with only signals exits 0: Claude stops, the user reads the signals at once in a `systemMessage`, and a new UserPromptSubmit hook (`craft-gate.py --prompt`) hands them to Claude once, with the next prompt. Only hard findings block a Stop and count toward the per-turn streak; with hard findings due, the fresh signals ride along on stderr as before. `craft-gate.py --staged` runs the Stop checks on the index for a git pre-commit hook (exit 1 on hard findings, signals on stderr).
- **P1-2** **Behavior change:** RHYTHM's limit moves from 25 to 58 lines without a Guide comment, the 90th percentile of the longest such run in antirez's long functions (rax, sds, redis `src/`). The cases of a flat switch neither lengthen nor break a run; functions named `test_*`, `*Test` or `*Tests` are exempt outside test paths too; `--report` gives the mean density, LOC per Guide comment, per file and overall. At Stop, an old long function is asked about only when the change lengthens its run.
- **P1-6** **Behavior change:** review signals follow complexity, not size. RHYTHM asks only of a function of >= 40 LOC that also has >= 9 branches or blocks nested >= 3 deep (three quarters of the long functions antirez guides have >= 9 branches); NO-DOC only of the exported API (a same-stem or `include/` header, `__all__` or the package's `__init__`, the package index, crate `pub`) and of functions that hand their caller something to release (returned allocation or open resource, a lock left held); NO-DESIGN only of modules with their own data structure, a binary layout, concurrency primitives or >= 2 public types; NO-TEACHER no longer fires on one-bit flags, `extern` array declarations or size arithmetic. Every signal is a question whose answer may be "none". AGENTS.md §1 and §5, craft-code, craft-review and the README say the same, and a Why comment goes with a bug fix when the reason is not visible in the code, not on every fix.
- **P2-4** **Behavior change:** a new review signal, NO-TEST, once per session: the session changed a struct, class or type, or added an exported function, and no test file changed. A new comment inside a type is no change. The README's Known limitations now say what stays with the model and human review.
- **P1-4** Every `SKILL.md` but the generated `craft-standard` stays within 6000 bytes (a test checks all of them): rules, one C example and the translation table; the examples per language moved verbatim to `skills/<skill>/references/<topic>-<lang>.md`, read only for the language in use, and C++, Zig, Go, Python, TypeScript, Java and Rust gained the examples they lacked. A test requires a reference for every language of a translation table; with `CRAFT_CORPUS`, another checks the rax and sds excerpts line by line against upstream.
- **P2-1** `skills/craft-design/references/encodings.md`: antirez's method for compact encodings in ten rules (dual representation, backlen, varint plus delta, variable-width headers, one-way width upgrades, presence bits, lossy quantization, when not to, persisted thresholds), the Redis defaults read in `redis.conf` (hash entries are 512) and a Teacher template, with Python examples the tests run. craft-design asks for an access-pattern table; craft-verify gains Proof 4, threshold crossings.
- **P2-3** The README covers Codex (`.agents/skills`), Gemini CLI (`GEMINI.md` with `@./AGENTS.md`, or `context.fileName`) and Cursor (`.mdc`), formats checked in each tool's documentation, and says that hooks and the Stop gate exist only in Claude Code. `scripts/install-git-hook.sh` makes `craft-gate.py --staged` a pre-commit hook, following `core.hooksPath` and never overwriting a hook that is not ours; the README gives the CI recipe.
- **Refinement 1** **Behavior change:** `XXX`, `HACK` and lowercase `todo:` are violations like a bare TODO, lowercase `fixme:` is a FIXME, and a `;` is a trigger only when at least two words follow it. `honey:` stays accepted.
- **Refinement 2** AGENTS.md §5 and craft-design count the same thing in the design check: exceptions to the invariant and cases of the interface. An exhaustive enumeration of algorithmic cases is not an exception, so rax passes.
- **Refinement 3** SessionStart deletes `craft-snap-*.json` and `craft-gate-*.json` older than 7 days from the temporary directory.
- **Refinement 4** Already done by P0-1: `craft_coverage_counter` is defined in the `CRAFT_OOM_IMPL` block.
- **Refinement 5** `craft-metrics.py --report` adds the comment-to-code line ratio per file and overall, and GRID, a lint for multi-column box grids in comments (three or more rulers; a one-row strip passes). Neither reaches the Stop gate.
- **Refinement 6** `.claude-plugin/icon.png`, a square crop of the logo, as the plugin directory asks.
- **Refinement 7** Version 0.0.4 in `plugin.json` and `marketplace.json`, and this changelog. The review's v1.x tags do not exist in the repository, so nothing is measured against them.
- **Check 1** **Behavior change:** generated files leave the gate's results (`*.gen.*`, a `Code generated ... DO NOT EDIT.` or `@generated` header in the first 10 lines, `linguist-generated` in `.gitattributes`) and still count as code using a name, so a symbol they use is no orphan.
- **Check 2** `scripts/replay-history.py` counts debt, BACKUP and heuristic findings in separate columns; only the heuristic column has the 2% target, rule violations have none.
- **Check 7** **Behavior change:** a failing git never blocks a session. The shared `git()` retries a transient failure up to 3 times; if git still fails, the snapshot is marked broken and the gate lets the session stop. Tested by failing the k-th git call, k = 1..N.
- **Check 11** The examples in `skills/*/references/` were built on real toolchains: 26 files of 36 compile (C, C++, Zig, Rust, C#, TypeScript, Python), and the C OOM harness and its driver ran on the real `rax.c`. `cleanup-zig` moved to the `std.Io` file API of Zig 0.17. The other 10 say "Illustrative, not compiled" at their head: Go, Java and Swift had no toolchain here, two C files are excerpts.
